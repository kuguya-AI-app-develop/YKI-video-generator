新增 Node 内置 test/VM 回归直接执行 `renderShot`，使用最小 DOM 替身，无外部测试框架：

- 已保存的历史内容在选择器保有焦点时同步到表单。
- 未保存编辑不会被轮询覆盖。
- 未改变的文本不会被重复赋值，避免轮询重置选区。
- 版本切换失败后可恢复到服务端选择的版本。
