# Windows NVIDIA 实机验收

本清单用于验证目标机器，未勾选项不代表已经通过。4070 Super / 32GB RAM 的首次试跑先读 [硬件条件与实验配置](HARDWARE.md)，并记录使用的个人配置。演示测试与真实 GPU 推理分开记录。

## 1. 机器与交付包

- [ ] Windows 11 x64；显卡型号、驱动版本、显存与系统内存已记录。
- [ ] `nvidia-smi` 正常，报告 `CUDA Version` 或 `CUDA UMD Version` 至少为 `13.3`，记录实际显存（4070S 为 12GB），不要把 32GB 显存当作硬门槛。
- [ ] 解压目录所在磁盘首次安装前至少 100 GiB 可用，建议保留更多视频产出空间。
- [ ] ZIP 文件 SHA256 与旁边 `.sha256` 文件一致。
- [ ] 项目完整解压到可写本地磁盘；本机未占用 8765、8188、8189 端口。

```powershell
Get-FileHash .\YKI-video-generator-0.1.0-windows.zip -Algorithm SHA256
nvidia-smi
Get-CimInstance Win32_ComputerSystem | Select-Object TotalPhysicalMemory
```

- [ ] 若 VC++ 安装触发 UAC，已按 Windows 提示完成管理员确认；若返回需要重启，安装状态为 `reboot-required`，重启后再次启动可继续，未提前标为 `ready`。

## 5. 版本、停止与恢复

- [ ] 只重做 S02，S01/S03 原始 MP4 与 WAV 的 SHA256 保持不变，S02 新增版本，成片更新。
- [ ] 选择 S02 旧版本，恢复对应提示词/旁白，自动合成新成片；新旧版本都保留。
- [ ] 锁定后不能编辑或重做；解锁保存后可修改。
- [ ] 手动编辑文本跨过两个轮询周期（超过 4 秒），内容不被刷新覆盖。
- [ ] 点击停止后当前任务结束；该启动器启动的模型/FFmpeg 进程退出，其他程序未被结束。
- [ ] 关闭服务再启动，处理中项目显示中断，可从未完成镜头继续；已完成素材保留。
- [ ] 某镜头失败时界面与 `project.json` 都记录错误，不产生伪成功成片。

停止不会保存尚未完成的扩散采样步骤；恢复粒度是完整镜头。配音生成中的取消可能需等待当前 CPU 合成调用返回。

## 失败时保留什么

不要反复卸载重装。保留这些本机文件作为定位依据：

- `runtime/logs/install-*.log`：安装与依赖检查。
- `runtime/logs/vc-redist-*.log` 与 `.json`：仅在补装系统 VC++ 运行库时产生，记录 Microsoft 安装器日志、签名、版本与退出码。
- `runtime/install-state.json`：安装状态与模型清单摘要。
- `logs/llama.log`、`logs/comfy.log`：模型服务日志。
- `projects/<id>/project.json`：阶段、错误、镜头及版本记录。
- 对应失败镜头的 WAV/MP4（如果已经生成），以及界面显示的错误文本。

日志和项目文件可能包含故事内容或本机路径；按需分享有关片段即可。

| 错误 | 处理 |
| --- | --- |
| 下载中断 / SHA256 不一致 | 保持已下载文件，重新运行安装器；支持续传，异常下载会另存供检查。不要绕过哈希校验。 |
| 无法访问 GitHub / Hugging Face | 检查本机网络和下载 URL，恢复后继续安装；安装器不内置第三方镜像。 |
| 驱动 CUDA 版本不足 | 更新 NVIDIA 官方驱动并重启，再运行安装器；单独安装 Toolkit 不能替代驱动升级。 |
| 缺少 VC++ DLL | 安装器会获取并验证 [Microsoft 官方 x64 VC++ 运行库](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist)后补装；UAC 被取消时重新运行。签名无效时禁止执行，检查网络和日志；需要重启时先重启再继续。已有另一版本但 DLL 仍缺失时，按日志使用 Microsoft 安装器修复现有运行库。 |
| CUDA out of memory | 先关闭其他 GPU 应用，保留 ComfyUI 日志及参数；本版本尚无自动降低画质策略。 |
| 找不到中文字体 | Windows 检查微软雅黑或黑体；也可在启动前设置 `AIGC_FONT` 为中文 TTF/TTC 字体路径。 |
| 旁白超过 14.5 秒 | 停止后缩短该镜头旁白，保存并继续。 |
| 端口占用 | 关闭自己先前启动的相同服务，或在 `settings.local.json` 修改相应端口；不要强杀不明进程。 |
